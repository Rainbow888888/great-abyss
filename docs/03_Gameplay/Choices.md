# Выборы

Главный принцип: **любой выбор должен иметь последствия.** Никаких декоративных решений.

Выборы — противопоставление двух полезных стратегий, не «добро против зла»:

- скорость ↔ разнообразие
- объём ↔ радость
- массовость ↔ индивидуальность
- производство ↔ исследование
- настоящее ↔ будущее
- стабильность ↔ эксперимент

Выбор одной стратегии закрывает или ограничивает другую — некоторые технологические/общественные пути становятся взаимоисключающими. Это важно для истинной концовки (см. `Endings.md`).

## Культурные последствия

Выборы меняют не только цифры, но и саму цивилизацию — через летописные записи, события, поведение, доступные технологии, внешний вид/характер развития. Подробнее — `docs/04_Content/Chronicle.md`.
