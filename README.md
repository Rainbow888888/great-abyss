# Great Abyss (Бездна)

Idle/incremental-игра на одном центральном объекте — Великой Бездне.

Это рабочий репозиторий проекта. Полное состояние идей и решений живёт здесь, в `docs/`, а не в чатах с ИИ. Любой новый чат с ИИ-агентом начинается с фразы «прочитай docs/» — не с пересказа.

## Структура

- `AGENTS.md` — правила для ИИ-агентов (Claude Code и любых других). Прочитать первым.
- `docs/01_Vision/` — концепция и принципы дизайна
- `docs/02_World/` — Бездна, Светлые, Тёмные
- `docs/03_Gameplay/` — ресурсы, выборы, концовки
- `docs/04_Content/` — Летописец
- `docs/06_Development/` — roadmap, тикеты, текущее состояние репозитория, открытые вопросы
- `docs/decisions/` — ADR: принятые решения с обоснованием

## Стек

Godot 4 (GDScript). Тестирование — HTML5/браузер. Релиз — десктоп/Steam (см. `docs/decisions/ADR-001-engine-godot.md`).

## Ключевая структура мира

Два переключаемых экрана, одна Бездна с общими характеристиками — снизу на светлом экране, сверху на тёмном (см. `docs/decisions/ADR-002-two-screens-shared-abyss.md`).

## Репозиторий

Публичный.

Стадия концепции завершена. Технической реализации ещё нет. Следующий шаг зафиксирован в `docs/06_Development/Tickets.md` (T0002).
