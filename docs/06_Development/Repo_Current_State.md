## Сделано
- Пакет документации: концепция, мир, ресурсы, выборы, концовки, летописец, roadmap, тикеты, ADR по движку.
- Три HTML/JS прототипа ядра (вне этого репозитория, для проверки ощущений от механики):
  - «Живой лес» — одноэкранный инкрементал, визуальный рост дерева по стадиям.
  - «Великая Бездна: два экрана» — независимые светлая/тёмная кампании с переключением.
  - «Бездна: Свет и Тьма» — единый экран, поделённый пополам, общий гейдж Бездны, три концовки (черновая калибровка чисел).
- T0001: пустой проект Godot 4 (`project.godot`), папки `/game /art /audio`, репозиторий инициализирован и запушен на GitHub как публичный (`great-abyss`).
- T0002: `game/scenes/Main.tscn` — `Node2D` "Main" с дочерним `Polygon2D` "Bezdna" (круг по центру экрана, тёмный цвет), без логики и без клика.
- T0003: `game/scenes/Main.gd` + «Источник» в `Main.tscn` — `Area2D` слева от Бездны, клик даёт +1 материал (переменная `material_count`, debug-label «Материал: N» и печать в консоль).
- T0004: Грухр (`Polygon2D` "Gruhr", зелёный кружок) рядом с Источником. Клик по Источнику запускает `Tween`-прыжок Грухра (вверх на 20px и обратно с отскоком), без звука и без AI-передвижения.
- T0005: кнопка «Бросить» (`Button` "ThrowButton"). Тратит весь накопленный материал разом, Бездна коротко пульсирует (`scale` 1.0 → 1.08 → 1.0). Первый замкнутый цикл: клик → материал → бросок → отклик Бездны.
- T0006: второй, пассивный Грухр (`Polygon2D` "GruhrPassive", тёмно-бирюзовый) + `Timer` "PassiveTimer" (3 сек). Раз в 3 секунды сам добавляет +1 материал и подпрыгивает — без клика игрока. Подтверждено человеком.
- T0007: интервал и величина прироста пассивного Грухра вынесены в ресурс `game/resources/PassiveGruhrStats.tres` (Data-Driven). Чистый рефакторинг — поведение не изменилось, проверено тем же логом.
- T0007.5: материал стал физическим объектом (`game/scenes/Material.tscn`). Клик по Источнику и тик пассивного Грухра роняют фигуру на землю (`GROUND_Y = 470`) с разбросом по x. Счётчик не растёт, label переименован в «В Бездне», кнопка «Бросить» временно бездействует — оживёт в T0007.6.

- Начат рабочий процесс: тикеты делаются в отдельных ветках (`tNNNN-...`), слияние в `master` — по подтверждению.
- В `AGENTS.md` добавлены Правила №8–10 (матрица приоритетов, вертикальный срез, «готово» ≠ «отполировано»); языковое правило переехало под №11. Добавлен `docs/06_Development/Verification.md` — как агент показывает и проверяет визуал через `screenshots/latest.png` вместо ручной пересылки картинок.
