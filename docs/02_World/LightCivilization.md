# Светлая цивилизация — Грухри

Грухри — светлые существа. Симпатичные, живые, смешные.

При нажатии на Грухри он издаёт звук вроде «Грухх-ррр!». Грухри радуются, когда строится здание — подпрыгивают, хором кричат при новом здании, бегут показывать редкость, чешутся от безделья.

## Базовый цикл
- добывают материал;
- строят;
- бросают материал в Бездну.

## Эскалация материала

Материалы постепенно становятся всё более масштабными:

Песок → камень → бетон → диваны/предметы → металл → здания → электростанции → более поздние технологии → синтез материи.

Важно: игрок должен *видеть*, как меняется процесс, а не только получать новые числа (Правило №2 в `AGENTS.md`).

## Не «однозначно хорошие»

Светлые тоже способны на неблаговидные поступки ради выживания. См. `docs/01_Vision/DesignPrinciples.md`.
