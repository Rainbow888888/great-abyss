# Проверка результата и обратная связь агенту

Проблема: агент пишет код, но не видит, что получилось на экране. Ручная пересылка скриншотов ломает ритм и плохо работает на Windows. Решение — игра снимает себя сама, агент читает файл.

## Скриншот-автолоад

> Статус: отложен — см. T0005.5 в `Tickets.md`. Сейчас работает самопроверка через `tools/capture.gd` (агент сам запускает Godot с окном, снимает/логирует нужное). Раздел ниже — на будущее, для показа скриншотов человеком.

В игре есть автозагрузка `Screenshot`, которая по нажатию клавиши (например, F12) сохраняет текущий вьюпорт в PNG:

```gdscript
extends Node

const DIR := "res://screenshots/"

func _unhandled_input(event: InputEvent) -> void:
    if event.is_action_pressed("screenshot"):
        take_screenshot()

func take_screenshot() -> void:
    DirAccess.make_dir_recursive_absolute(DIR)
    var img := get_viewport().get_texture().get_image()
    img.save_png(DIR + "latest.png")
```

Действие `screenshot` заводится в Project Settings → Input Map.

## Как показывать результат агенту

Не вставлять картинку в терминал. Просто назвать путь:

> «Запусти сцену, я нажму F12. Потом посмотри `screenshots/latest.png` и скажи, соответствует ли это тикету.»

Работает на всех платформах, в отличие от вставки из буфера (на Windows она часто не срабатывает).

Для сравнения «было/стало» — сохранять под разными именами и просить сравнить два пути.

## Что проверяется чем

| Что нужно проверить | Чем |
|---|---|
| Проект открывается, сцена грузится без ошибок | `godot --headless --quit` — можно доверить агенту |
| Скрипты компилируются, нет ошибок парсинга | headless-запуск, вывод в консоль |
| Как выглядит на экране | скриншот в файл, агент читает PNG |
| Ощущается ли механика интересной | **только человек, руками, играя** |

Важно: `--headless` отключает рендеринг. Для скриншотов Godot должен запускаться с окном.

## Регрессии визуала — позже

Когда визуал устаканится, имеет смысл посмотреть на GDSnap (снапшот-тестирование: хранит эталонный скриншот, сравнивает с новым, отдаёт диф в пикселях). Сейчас рано — Правило №4.

## Граница ответственности

Агент может подтвердить: «код компилируется, сцена грузится, на скриншоте круг тёмного цвета по центру».

Агент НЕ может подтвердить: «в это интересно играть». Это Правило №5 — проверяется только человеком за игрой. Скриншот-цикл ускоряет проверку формы, но не заменяет проверку сути.
