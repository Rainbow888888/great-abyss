# Roadmap

Не делаем всю игру сразу. Двигаемся фазами, каждая фаза = один или несколько тикетов из `Tickets.md`. Если фаза не заходит — разбираемся до следующей (Правило №5).

## MVP-ядро (F0–F7)

Светлая сторона: **Бездна + Грухри + материал + засыпание + базовый idle-цикл.** Тёмная сторона, второй экран, Эхо, концовки — сознательно за пределами этой дорожной карты.

- [x] **F0. Скелет** — репозиторий, структура папок, документация, пустой проект Godot.
- [x] **F1. Один экран** — сцена `Main.tscn` в разрезе (ADR-003): поверхность, земля, Бездна как полость под ней, Священный Монолит рядом.
- [x] **F2. Клик = добыча** — клик по Монолиту роняет объект-материал на поверхность.
- [x] **F3. Первый Грухр** — спавн Грухров, реакция на добычу (прыжок).
- [x] **F4. Бросок в Бездну** — Грухр несёт материал к зеву и сбрасывает, Бездна пульсирует.
- [x] **F5. Пассивный idle** — простая автоматизация (второй Грухр работает без клика).
- [x] **F6. Сохранение** — автосейв в JSON.
- [ ] **F7. Полировка ядра** — первые записи Летописца готовы (T0010, T0011), проверка «интересно ли это уже сейчас» — T0012, ждёт человека.

## Давление Бездны (F8)

Бездна огрызается. Несобранное пропадает, куча не растёт вечно, игрок может вмешиваться руками.

- [ ] **F8. Давление Бездны** — всасывание (T0013), штраф за перепроизводство / высота кучи (T0014), ручное подталкивание кликом (T0015).

## Расшивание узкого места (F9)

Транспорт — узкое место. Даём инструменты его расширить, но апгрейд меняет поведение, а не цифру.

- [ ] **F9. Узкое место** — апгрейд скорости носильщика (T0016), анимация/визуал прокачки (T0017).

## Мир бьёт в ответ (F10)

По заветам Dwarf Eats Mountain: мир отвечает на жадность, и удар приходится по самой хрупкой части — по транспорту.

- [ ] **F10. Катаклизм** — дыхание Бездны, периодическая атака (T0018), наказание носильщиков (T0019).

## Эскалация эгоизма (F11)

Эскалация источников и моральный образ: игрок строит, потом разбирает и скармливает то, что сам создал.

- [ ] **F11. Эскалация** — Жертвенный Дом как новый источник (T0020), устаревание Монолита (T0021), расширение плеча переноски + адаптация камеры (T0022).

## Дальше — не планировать сейчас

Тёмная сторона, второй экран, Эхо, концовки,更多 стадий Бездны — всё это ждёт результатов F8–F11.
