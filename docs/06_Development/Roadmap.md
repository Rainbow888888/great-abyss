# Roadmap — только MVP-ядро

Не делаем всю игру. Сначала проверяем: **Бездна + Грухри + материал + засыпание + базовый idle-цикл.** Только светлая сторона. Тёмная сторона, второй экран, Эхо, концовки — сознательно за пределами этой дорожной карты (см. Правило №4 в `AGENTS.md`).

- [x] **F0. Скелет** — репозиторий, структура папок, документация, пустой проект Godot.
- [ ] **F1. Один экран** — сцена `Main.tscn`, Бездна (круг) в центре без логики, Источник материала рядом.
- [ ] **F2. Клик = добыча** — клик по Источнику даёт материал, Источник визуально уменьшается/меняется.
- [ ] **F3. Первый Грухр** — спавн одного Грухра, при клике/постройке — реакция (звук, прыжок).
- [ ] **F4. Бросок в Бездну** — материал тратится, Бездна визуально реагирует (растёт/меняет цвет/пульсирует).
- [ ] **F5. Пассивный idle** — простая автоматизация (второй Грухр работает без клика).
- [ ] **F6. Сохранение** — автосейв в JSON.
- [ ] **F7. Полировка ядра** — первые записи Летописца, проверка «интересно ли это уже сейчас».

Каждая фаза = один или несколько тикетов из `Tickets.md`. Дальше (тёмная сторона, Эхо, концовки, эпохи материала) — планируется только после того, как F0–F7 подтвердят, что ядро цепляет.
