# ADR-002: Два экрана, одна Бездна

## Статус
Принято.

## Контекст
Раньше рассматривались два разных варианта структуры мира:
1. Один экран, поделённый пополам (верх/низ), с общим визуальным гейджем Бездны в центре — этот вариант был проработан как играбельный прототип «Бездна: Свет и Тьма».
2. Два отдельных переключаемых экрана — Светлый мир и Тёмный мир, как два вида одного мира.

Нужно было выбрать один, чтобы не путать тикеты дальше.

## Решение
**Два отдельных переключаемых экрана.** Не один разделённый экран.

- Бездна — одна сущность с общими характеристиками (уровень пробуждения, скорость всасывания, стадия развития) на оба экрана.
- На **светлом экране** Бездна расположена внизу: Светлые кидают материал сверху вниз, засыпая её.
- На **тёмном экране** та же Бездна расположена наверху: из неё всё выпадает вниз, Тёмные это собирают.
- Переключение между экранами — в любой момент, без ограничений.

## Последствия
- Не нужен общий «разделённый» UI-контейнер — это две отдельные сцены/виды в Godot, читающие общее состояние Бездны.
- Действие на одном экране (клик, постройка, апгрейд) немедленно отражается на характеристиках Бездны, видимых на другом — единый источник истины, не два параллельных счётчика.
- Прототип «Бездна: Свет и Тьма» (один разделённый экран) остаётся справочным материалом по ощущениям от механики баланса/концовок, но не является образцом визуальной структуры — эта часть в нём считается устаревшей.
