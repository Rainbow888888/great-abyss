# Тёмная цивилизация

Тёмные живут по другую сторону Бездны. Их мир буквально перевёрнут относительно светлого.

Используют тот же основной ресурс — воздух, но иначе:

- усиливают всасывание;
- развивают устройства, которые втягивают воздух;
- строят собственную инфраструктуру;
- помогают Бездне расширяться/развиваться.

У тёмных — свои здания и технологии, не зеркальные версии светлых.

## Не «однозначно злые»

Внешне тёмные/угрожающие, но внутренне должны быть такими же живыми, симпатичными и неоднозначными, как Грухри. Тёмные тоже способны поступать по совести. Игрок должен постепенно сомневаться в простом делении на добро и зло.
