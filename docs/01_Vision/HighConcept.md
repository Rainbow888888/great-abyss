# High Concept

Idle/incremental-игра на одном центральном объекте — Великой Бездне.

Бездна — огромный живой разлом/портал в центре мира. Она постепенно растёт и втягивает воздух. Из неё появляются существа, которые мешают светлой цивилизации и одновременно являются частью тёмной цивилизации.

Игрок по очереди управляет двумя сторонами:

- **Светлые — Грухри**
- **Тёмные — существа Бездны**

Обе стороны развиваются одновременно. Если игрок долго развивает одну сторону, другая начинает слабеть.

У игры должны быть простота, юмор, визуальная жизнь и постепенно раскрывающаяся история.

## Ближайший фокус (не вся игра сразу)

Сначала проверяем только ядро:

> **Бездна + Грухри + материал + засыпание + базовый idle-цикл.**

Тёмная сторона, второй экран, Эхо, концовки — сознательно НЕ в MVP. Сначала доказываем, что ядро интересно само по себе (см. Правило №5 в `AGENTS.md`).

## Прогресс — это не только числа

Игрок должен ощущать:
1. экономический рост;
2. визуальное развитие;
3. технологическую эскалацию;
4. изменение цивилизации;
5. продвижение истории;
6. приближение Бездны к пробуждению.

## Игры-ориентиры (не копируем — разбираем)

- **Gnorp Apologue** — один центральный объект, визуальная прогрессия, редкий ресурс.
- **Dwarf Eats Mountain** — простая идея, один экран, ощущение поглощения огромного объекта.
- **The Monolith** — развитие вокруг одного объекта, эпохи, завершённая структура.
- **Spaceplan** — абсурдный юмор, чёткая конечная цель.
- **Crank** — одна механика, короткий путь к завершённой истории.
- **A Dark Room** — минимализм, история через дозированную подачу.
- **Increlution** — долгосрочная прогрессия, смерть/перезапуск как часть продвижения.
- **Universal Paperclips** — эскалация масштаба, финальная стадия как часть драматургии.
